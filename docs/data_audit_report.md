# African Crop Yield Intelligence

D'apres la documentation, certain traitement ont ete appliquer sur le dataset notamment  :

- Harmonisation des noms de cultures,
- la suppression des doublons,
- Harmonisation des références géographiques et attribution d'identifiants administratifs uniques,
- Détection et suppression des rendements aberrants dans les données ponctuelles, à l'aide de seuils calculés par culture à partir des distributions régionales,
- Conservation des valeurs aberrantes dans les données nationales et infranationales.


Aucune information sur les colones n'est donnees dans la documentation.
